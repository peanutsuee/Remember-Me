# Project Origin

Remember-Me's original concept, product design, and independent project were
initiated by Ting (peanutsuee).

## Public timeline

- The Remember-Me concept formed as an independent image memory and management
  direction before its public repository was initialized.
- On July 23, 2026, the first persistent image asset capability was integrated
  into Ombre Brain.
- On July 24, 2026, the private integrated implementation passed its stable
  acceptance point.
- On July 25, 2026, the independent public Remember-Me repository was
  initialized.
- Stage 7B later replaced the six core modules with independently
  reimplemented CPAL-1.0 versions produced from a frozen behavioral
  specification, public contracts, sanitized tests, and data compatibility
  requirements through a documented clean-room engineering process.
- The public architecture makes Remember-Me the only long-term core code source.
- Ombre Brain is planned to consume that core through a thin plugin or adapter.

This history records public project provenance only. It intentionally excludes
private conversations, credentials, private data, production infrastructure,
user assets, and local private paths.
