# Trademarks and Project Identity

The `Remember-Me` project name, official marks, and official visual assets are
managed separately by the project maintainers. The open-source license does not
automatically authorize anyone to present a modified distribution as an
official release.

Forks and modified versions should be labeled clearly. Fair and accurate
references to project origin are not restricted by this policy.

No claim is made here that a trademark registration has been completed.
